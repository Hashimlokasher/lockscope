LockScope

A Chrome DevTools panel for the Web Locks API.

Inspect navigator.locks across tabs: holders, FIFO waiters, observed durations, a canvas timeline, optional tab labels, and opt-in exact instrumentation.

The base extension requires no permissions. Everything runs locally; there is no network code, analytics, or persistence of lock names.
