LockScope demo

Exercises for navigator.locks. Open DevTools → the LockScope panel, then press a button.

Web Locks is unavailable. Open this page over http://localhost or HTTPS. Locks require a secure context.

Exclusive hold

Hold resource-a for 8 seconds. One holder, no waiters.

Queue writers

Three exclusive requests for resource-a. Watch the FIFO queue and growing wait times.

Shared readers

Three shared holders of resource-b, then one exclusive writer that waits for all of them.

Cross-tab

Open a second tab of this origin that immediately holds resource-a. Both tabs share one lock manager.

Clean up

Releases everything this page is holding and aborts anything still queued. Closing the tab releases its locks too.

Edge cases

Abort while queued

A holder blocks abort-queued; a waiter aborts after 800 ms and disappears from the queue.

Abort after grant

Acquire abort-granted, call abort() after it is granted, and see that the lock stays held.

ifAvailable skip

Hold if-available; a second request skips instead of queueing, so no pending entry appears.

steal takeover

Hold steal-demo, then steal it. The original callback keeps running but its lock is gone.

Worker-held lock

A dedicated worker holds worker-lock for 8 seconds. It appears with its own clientId.

Two-tab deadlock

Opens a second tab. Each tab holds one lock and waits for the other; release from either tab to break it.
